          What no tool can remove

          • Anything you can see in the picture: faces, street signs, reflections, screens.
          • The file name, unless you use the neutral name this page suggests.
          • A camera's sensor fingerprint, which can link photos to one camera.
          • Invisible watermarks woven into the pixels, for example in some AI-generated images.
