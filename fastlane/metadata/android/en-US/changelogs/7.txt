Saving over an existing file now replaces it whole. If a storage app would leave part of the older file in place, the save fails and says so, and the mixed file is removed, so the end of an older, longer file, such as the video of a Motion Photo, can never stay behind the clean picture. Text stored under names such as constructor in PNG text or XMP is now found and removed. Full log: https://github.com/StormberryAS/MetadataScrubber/blob/main/CHANGELOG.md
