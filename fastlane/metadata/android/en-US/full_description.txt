MetadataScrubber shows what a photo carries besides the picture itself, lets you choose what to remove, and then reads the new file back so you can see what is left. GPS position, camera serial numbers, owner names, dates, a built-in preview image and more.

It declares no Android permissions at all. There is no internet permission, so it cannot send your photos anywhere, and no storage permission either: pictures come in through the system file picker or a share from your gallery, and go out through the system save screen or a share. Check it yourself before installing:

    aapt dump permissions <the APK you downloaded>

The only line you should see is the package name.

- Shows before it removes. Every item found in the file is listed, grouped by what it reveals: Where, Who, When, Device, Hidden extras and Technical.
- Colour tiers guide the choice. Red means remove before sharing publicly, amber means think about it, green means harmless and useful. Red items are ticked by default.
- Lossless by default. Removing metadata touches only the metadata; the picture itself is not saved again.
- Crop, resize and convert when you need to, for JPEG, PNG and WebP.
- Reads the result back, so the list shows what remains in the new file.
- Neutral file names. The phone's file name, which carries the date and time, is never reused. Results are named like image.public.jpg.
- Share a photo into the app from your gallery, then save the clean copy or share it straight on.

Supported formats: JPEG, PNG, WebP and HEIC. HEIC metadata can be removed, but cropping and resizing HEIC are not available in the app, because Android's web engine cannot open HEIC pictures.

What it cannot remove: anything visible in the picture, the file name you choose, a camera's sensor fingerprint, and invisible watermarks woven into the pixels.

The app runs the same files as the website at metadata.stormberry.as, bundled inside it and working offline. The build checks that every one of them is byte for byte identical to the website's copy, apart from one added line in index.html that loads a small Android bridge for saving and sharing.

This is a functioning prototype from Stormberry Labs, MIT licensed. Check the read-back list before you share a file.
